# TrainPilot

TrainPilot на коротком прогоне PyTorch говорит, видеокарта считает или ждёт данные, проверяет смешанную точность и даёт несколько строк, которые вы вставляете сами. Профайлер оставляет трассу. TrainPilot на том же seed и тех же батчах проверяет одну правку и пишет, стал ли короткий тест быстрее и не разъехался ли loss.

## Было / стало

Короткий прогон на Tesla T4: 10 шагов прогрева не входят в замер, дальше 30 шагов, в таблице медиана. Полное обучение по этим числам только оценка, не измерение. Loss не разошёлся, NaN не было. Это не доказательство, что модель не изменилась.

| Пример | Диагноз | Было | Стало | Что вставить |
|---|---|---|---|---|
| 01 CIFAR, маленькая CNN | 89.4% шага — ожидание следующего батча | счёт на GPU 11.4 мс | счёт на GPU 8.0 мс | `num_workers=2`, `pin_memory=True` |
| 02 TinyStories, FP32 | GPU занят | 493.4 мс | 151.5 мс, в 3.26 раза, FP16 | FP16 и `GradScaler` |
| 03 ResNet-50 | GPU занят, ожидание около 2% | 372.0 мс | 152.0 мс, в 2.45 раза, FP16 | FP16 и `GradScaler` |

У CIFAR почти весь шаг — загрузка картинок на процессоре. 11.4 мс и 8.0 мс — только счёт, когда батч уже в памяти, поэтому вставляется загрузчик, а не FP16. У TinyStories и ResNet-50 карта занята, и FP16 укоротил шаг. На T4 точность FP16, не BF16. Фразу «ускорять почти нечего» пишем только если короткий тест сам не показал явного ускорения.

## Быстрый старт

```bash
pip install -e .
trainpilot run train.py
trainpilot run train.py --compile
```

Команда выполняет скрипт и пишет `trainpilot-report.md`. Скрипт она не меняет. Чтобы в отчёте были цифры, скрипт сам вызывает замер:

```python
from trainpilot import compare_mixed_precision, diagnose, measure_batches, render_report

diagnosis = diagnose(measure_batches(loader, step))
experiment = compare_mixed_precision(model, optimizer, loader, loss_fn, seed=0)
print(render_report(diagnosis, experiment))
```

`step(batch)` делает один шаг обучения и возвращает число примеров в батче. `loss_fn(model, batch)` считает скалярный loss именно на переданной модели. Без видеокарты отчёт пишет `GPU not found` и не падает.

Тот же короткий прогон трёх примеров на одной T4 лежит в `notebooks/trainpilot_colab.ipynb`.

## Ограничения первой версии

- Одна видеокарта NVIDIA. Несколько GPU и распределённое обучение не поддерживаются.
- Обычный цикл PyTorch. Скрипт не переписывается сам.
- Размер батча и память не подбираются.
- Конкретный процент ускорения не обещается. В таблице — результат одного короткого прогона на T4.
- «Обучение не сломалось» значит: loss не разошёлся и NaN нет.
- В ноутбуке оставьте `num_workers=0`, если лишние процессы роняют сеанс. Число воркеров не поднимается выше 2. Если `num_workers=2` и `pin_memory` уже стоят, отчёт это не повторяет и советует облегчить загрузку.
- `torch.compile` выключен, пока его не попросят (`--compile` или `try_compile=True`). Он меряется поверх AMP и сравнивается с шагом AMP. Время подготовки считается отдельно от шага.
